# 12 — Content Checklist

Complete and verify these details before publishing.

## Identity
- [ ] Name spelling and preferred display name
- [ ] Current course, department, college and year
- [ ] One-sentence professional introduction
- [ ] Professional email address
- [ ] GitHub URL
- [ ] LinkedIn URL
- [ ] Resume PDF

## Projects
For each project:
- [ ] Accurate title and short summary
- [ ] Problem being solved
- [ ] Your individual contribution
- [ ] Current status (prototype, in progress, completed)
- [ ] Verified technologies used
- [ ] GitHub repository link
- [ ] Demo link, if available
- [ ] Screenshots or architecture diagram
- [ ] Results and evaluation method, if reporting metrics
- [ ] Known limitations and future improvements

Potential featured work to review:
- Exo-Scan AI
- SentinelMesh AI
- ACM automation work

Do not claim a project is deployed, production-ready, open source or award-winning unless that is accurate and verifiable.

## Experience and activities
- [ ] Confirm official role titles
- [ ] Confirm start/end dates
- [ ] Distinguish finalist, participant, shortlisted and winner
- [ ] Add evidence or links where appropriate
- [ ] Do not list planned activities as completed achievements

## Skills
- [ ] Separate confident skills from currently learning tools
- [ ] Remove technologies you cannot discuss in an interview
- [ ] Group skills by category
- [ ] Avoid arbitrary percentage proficiency bars

## Visual assets
- [ ] Use project screenshots you own or have permission to publish
- [ ] Compress images and use descriptive filenames
- [ ] Add alt text
- [ ] Check that no private keys, personal records or confidential project data appear in screenshots

## Final review
- [ ] Proofread all copy
- [ ] Test every link
- [ ] Test resume download
- [ ] Test contact form
- [ ] Check mobile layout
- [ ] Check dark mode
- [ ] Check keyboard navigation and reduced motion
